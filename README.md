# 🐟 鱼窝档案库（notes）

> 这是「鱼窝」——我的个人数字小窝——的**云端档案库**。
> 网站跑在自己的云服务器上，这里负责把每天产生的珍贵东西，自动存一份到 GitHub，防个万一。

---

## 一、这个仓库是干嘛的？

简单说：**三个自动化的归档机器人，每天定时往这里存东西。**

服务器上的程序每天按点干活，把当天新产生的内容整理好、提交到这个仓库。全程无人值守，失败了会自动重试。

## 二、收集哪些东西？

| 文件夹 | 收什么 | 说明 |
|--------|--------|------|
| `trending/` | GitHub 榜单日报 | 每天的开源趋势整理，按月份分文件夹，一篇一天 |
| `diary/` | 鱼的日记 | 我的 AI 小鱼「大肥鱼」每晚写的日记，**一篇一个文件**，按 年/月 归档 |
| `backup/` | 整站每日备份 | 网站全部文件 + 大肥鱼的配置，一天一个日期文件夹 |

## 三、收集的顺序（每天的时间表）

```
20:00 ~ 24:00   大肥鱼醒来，逛论坛、写日记（这是所有内容的源头）
 01:00          大肥鱼例行重启，清空内存，满血复活
 05:00          📦 每日归档：日记逐篇入库 + 整站打包备份
 08:30          📧 三份日报（榜单/日记/统计）寄到邮箱
 每 6 小时      网站重新组装一次，内容保持新鲜
```

## 四、backup/ 备份包里有什么？

每天一个文件夹（如 `backup/2026-11-19/`），里面固定三样：

- **`site.tar.gz`** —— 网站全量备份：
  - `scan.py`：网站母版（所有页面的样式和逻辑都在这一个脚本里）
  - 资产台账数据：在册资产、历史变更流水、每日余额账本
  - 访问计数、生成的 5 个网页、cgi-bin 接口脚本、端口配置
- **`whale.tar.gz`** —— 大肥鱼的公开配置与自动化脚本（插件配置、作息安排、工具脚本、角色设定）
- **`manifest.txt`** —— 内容清单和恢复说明（哪天打开都能看懂）

⚠️ **重要约定**：所有凭据类文件（邮箱密码、各种服务密钥）**永远不会**进入本仓库——仓库是公开的，不能把家门钥匙一起挂着。完整恢复时这几样需要重新提供。

## 五、文件格式速查

- `.md` — 带排版记号的纯文本，日记、日报、说明都是它，随便什么工具都能打开
- `.json` — 结构化数据，程序记的账（台账、配置）
- `.jsonl` — 一行一条记录的流水账（每日余额追加写入）
- `.tar.gz` — 打包压缩的「行李袋」，备份本体，平时不用打开

## 六、想恢复怎么办？

1. 从 `backup/<日期>/` 下载 `site.tar.gz` 和 `whale.tar.gz`；
2. 解压到服务器的原位置（包内已带完整路径）；
3. 重新提供凭据类文件，启动网站程序即可。

详细的清单对照，看每个备份文件夹里的 `manifest.txt` 就行。
